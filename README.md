# Inventory Report

CLI em Python que importa dados de estoque a partir de arquivos e gera relatórios de inventário (entradas, saídas e totais por produto).

## Tecnologias

- Python
- Typer (interface de linha de comando)
- pytest

## Como rodar

```bash
pip install -e .
python -m inventory_report <argumentos>
```

## Testes

```bash
pytest
```
